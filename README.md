# Sonny

Sonny is a lightweight personal agent that I'm building to better understand how modern AI agents work under the hood (and for fun).

## Current capabilities

- Interactive terminal chat
- OpenRouter-backed language models
- Tool calling with human approval
- File, shell, and web tools
- Markdown-based agents and skills
- Persistent and resumable sessions
- Automatic and manual context compaction
- Slash commands and configuration hot reload
- Telegram messaging with per-conversation sessions
